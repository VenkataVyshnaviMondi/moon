## Platform
web

## Product Purpose
Present Mooncrafters' connected digital marketing and IT services, explain its working approach, introduce its CEOs and verified client community, and help visitors begin a project enquiry.

## Capabilities and Constraints
The current product is a responsive single-page agency site: Home, Services, About, Process, Work/client community and Contact. The header and footer use section anchors, not separate routed pages.

Digital Marketing contains exactly Branding, Social Media Marketing, Google Ads, Meta Ads and YouTube Marketing. IT Services contains exactly Web Designing, IT Solutions and Zoho Projects. Selecting a service row moves to Contact and preselects that service. The form also offers “Not sure yet.”

The enquiry form requires a full name, valid email and project description of at least 20 characters. Phone is optional. In the default static deployment it prepares an email draft addressed to mooncrafters@gmail.com, then asks the visitor to open their email app, review and send it. A prepared draft is never reported as a sent enquiry. Without JavaScript the native form action opens the visitor's email app.

A deployment can configure VITE_CONTACT_ENDPOINT to a relative path beginning with one slash or an HTTPS URL. When configured, the browser posts JSON, exposes pending/success/error status, prevents duplicate submissions and times out after 20 seconds. No backend endpoint is included in this repository; the hosting setup must supply and operate that endpoint before enabling it.

There is no current careers page, job application workflow, client-result dashboard or testimonial carousel. No vacancies, performance metrics, case-study results or endorsements are established by the supplied evidence.

## Brand Commitments
The current user-directed world is a deep navy foundation, bright lime/cyan/coral accents, restrained gradients, bold-scale Sora typography, generous space and crisp static geometric SVG illustration. Use the supplied Mooncrafters logo and real company assets.

Keep the tone warm, clear, practical and professional. The customer promise is growth and satisfaction through thoughtful work: quality matters more than quantity. Services should feel connected rather than offered as unrelated products.

Content must be readable immediately. Keep motion to short CSS state changes, preserve keyboard access and respect reduced motion. The current loading path has no autoplay, particles or WebGL. Root DESIGN.md and .impeccable/surfaces/home.md describe the implemented visual system and home-page direction.

## Implementation and Delivery
React and TypeScript use reusable Header, Hero, ServicesSection/ServiceCard, ProcessSteps, ContactForm, Footer, Icon and client-logo components. Styling is ordinary CSS. One locally hosted Sora variable WOFF2 is preloaded; no remote font request is needed.

The production build type-checks, runs Vite, loads src/App.tsx through Vite ssrLoadModule and renders the complete page with React renderToString into dist/index.html. The browser hydrates this markup with hydrateRoot. The development entry can createRoot when prerendered markup is absent.

Deploy the generated dist directory to a static host. Prerendered headings, navigation, services and contact markup are present in the production HTML before JavaScript runs. The optional contact endpoint is separate from that static deployment.
